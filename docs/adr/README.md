# Architecture decision records

ADRs capture durable choices that future code should not silently reverse.

Status values:

- **Proposed** — under consideration;
- **Accepted** — current architectural rule;
- **Superseded** — replaced by a later ADR that links back to it;
- **Rejected** — considered and intentionally not adopted.

Create a new numbered file for a new decision. Do not rewrite the rationale of an accepted ADR to
make history appear cleaner; supersede it when the decision changes.
